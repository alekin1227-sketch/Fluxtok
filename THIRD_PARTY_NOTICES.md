# Componentes e serviços de terceiros

O Fluxtok utiliza bibliotecas open source e integrações externas. Antes de redistribuir o software em outro modelo comercial, confira as versões efetivamente instaladas e os respectivos arquivos de licença.

Principais dependências do projeto:

- Next.js — licença MIT;
- React / React DOM — licença MIT;
- Prisma ORM / Prisma Client — licença Apache-2.0;
- bcryptjs — licença MIT;
- Nodemailer — licença MIT;
- Zod — licença MIT;
- TypeScript — licença Apache-2.0.

Serviços externos como TikTok Shop, Mercado Pago, Railway e TiDB possuem termos próprios e não são licenciados pelo Fluxtok. O uso das APIs depende dos contratos, políticas, credenciais e aprovações de cada provedor.
